# КОМНАТА: Кто украл будущее

Браузерный платформер по подкасту Mash Room. Документация — в [`docs/`](docs/README.md): ТЗ, концепт, референсы.

```sh
npm install
npm run dev      # дев-сервер
npm test         # Vitest
npm run lint     # ESLint
npm run build    # проверка типов + сборка в dist/
npm run levels   # пересобрать карты уровней (src/data/levels/*.json) из scripts/levels/
```

Управление: игрок 1 — стрелки, Z прыжок, X действие; игрок 2 — WASD, G прыжок, H действие; Enter — Start; M — звук.
Взять предмет — упереться в него стрелкой и нажать действие. Спрыгнуть с тонкой платформы (стул, стол, подоконник, полка) — ↓ + прыжок или ↓ + действие с пустыми руками.
Геймпады: первый подключённый — игрок 1, второй — игрок 2.

Сейчас играбельны уровень 1 «Кофейня» (зал, кухня, мойка, подвал с Агранович) и уровень 2 «Серверная» (серверная со спуском, машинный зал с Ураловым). Уровни 3–9 — пустышки: Z — пройти, X — проиграть. Ход работ и принятые решения — [`docs/PROGRESS.md`](docs/PROGRESS.md).

Отладка (только `npm run dev`): F1 — неуязвимость, F2 — к арене босса, F3 — выбор уровня, F4 — хитбоксы, F5 — замедление ×0,25.

Звук: эффекты-заглушки генерируются в коде (`src/config/sfx.ts`). Для разработки их можно подменить своими файлами — см. `assets/dev-overrides/README.md` (в git и прод-сборку не попадают).

Устройство: вся игровая логика — в `src/sim/` (без Phaser, тестируется в Vitest), Phaser только рисует (`src/render/`, `src/scenes/`).
Карты собираются скриптом в формат Tiled JSON — их можно открыть и править в Tiled (тайлсет-заглушка — `assets/tilesets/placeholder.png`).
