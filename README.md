# КОМНАТА: Кто украл будущее

Браузерный платформер по подкасту Mash Room. Документация — в [`docs/`](docs/README.md): ТЗ, концепт, референсы.

```sh
npm install
npm run dev      # дев-сервер
npm test         # Vitest
npm run lint     # ESLint
npm run build    # проверка типов + сборка в dist/
```

Управление: игрок 1 — стрелки, Z прыжок, X действие; игрок 2 — WASD, G прыжок, H действие; Enter — Start; M — звук.
Геймпады: первый подключённый — игрок 1, второй — игрок 2.

Сейчас этап 0 (каркас): сцены-пустышки. На заглушке уровня: Z — пройти, X — проиграть; там же монитор ввода обоих игроков.
